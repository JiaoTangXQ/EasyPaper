# EasyPaper identity

The curled-paper lowercase e is original vector geometry: one white curved silhouette inside an ink-black rounded tile, with a small vermilion ink dot. The palette is ink `#191817`, white, and vermilion `#bd392b`.

The EasyPaper wordmark uses outlined Satisfy lettering with its native spacing and kerning. The connected handwriting preserves thick and thin strokes rather than using a typeset serif. SVG outlines keep the artwork consistent at every scale and require no font request at runtime.

Lettering source: [Satisfy in Google Fonts](https://github.com/google/fonts/tree/main/apache/satisfy). The Apache 2.0 license is included in `LICENSE-Satisfy.txt`. The font has been converted to SVG outlines for the EasyPaper wordmark; these files are logo artwork, not a redistributed font family.

Satisfy font copyright: Copyright (c) 2011 by Font Diner, Inc. All rights reserved.

`logo.svg` is the full horizontal lockup; `mark.svg` is the standalone symbol; `wordmark.svg` is the lettering. Interface use is shared through `src/components/Brand.tsx`. PDF contents and user annotation colors are independent of this identity.
